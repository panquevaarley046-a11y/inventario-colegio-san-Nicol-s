📋 Descripción General del Sistema

El Sistema de Inventario San Nicolás es una aplicación web desarrollada con tecnologías frontend puras (sin frameworks ni backend), diseñada para gestionar el inventario de equipos y recursos de la Institución Educativa Técnica San Nicolás.

Objetivo técnico

Proveer una interfaz visual moderna y funcional sin dependencia de servidores externos. Todos los datos del usuario se almacenan en localStorage.

Características técnicas principales

  • Sin backend ni base de datos remota
  • Persistencia de datos con localStorage
  • Generación de QR mediante API externa (qrserver.com)
  • Exportación a PDF con la librería jsPDF
  • Diseño 100% responsivo con CSS Grid y Flexbox
  • Efectos visuales con CSS backdrop-filter y gradientes

3. Chat Asistente

// Respuestas automáticas por palabras clave if (texto.includes('mantenimiento')) { respuesta = "38 equipos en mantenimiento..."; } else if (texto.includes('qr')) { respuesta = "Usa el panel derecho para generar QR..."; }

4. Módulo de Perfil

Lee y escribe en localStorage bajo la clave 'perfil_usuario'. Soporta foto en base64, avatar emoji o iniciales.

💾 Uso de localStorage

Estructura del objeto guardado

{ "nombre": "Administrador", "apellido": "San Nicolás", "correo": "admin@sanicolas.edu.co", "telefono": "3001234567", "rol": "Administrador", "sede": "Institución San Nicolás", "cargo": "Gestor de Inventario", "foto": "data:image/jpeg;base64,...", "avatar": "👩‍🏫", "password": "******" }

Leer el perfil desde cualquier página

const p = JSON.parse(localStorage.getItem('perfil_usuario') || '{}'); if (p.foto) { document.getElementById('sidebar-avatar-img').src = p.foto; document.getElementById('sidebar-avatar-img').style.display = 'block'; } else if (p.avatar) { document.getElementById('sidebar-avatar-text').textContent = p.avatar; } if (p.nombre) document.getElementById('sidebar-name').textContent = p.nombre; if (p.correo) document.getElementById('sidebar-email').textContent = p.correo;
ℹ️ localStorage guarda datos solo en ese navegador y dispositivo. Si el usuario limpia el caché, los datos se pierden.

➕ Cómo Agregar un Nuevo Salón

1

Crear el archivo HTML

Copia salon1.html y renómbralo (ej: salon10.html). Cambia el nombre y código dentro del HTML.

2

Agregar tarjeta en salones.html

Busca el div .room-grid y agrega:

<div class="room" onclick="window.location.href='salon10.html'" data-name="Salón 10"> <h3><span>👨‍🏫</span> Salón 10</h3> <p>Código: SN-10</p> </div>
3

Agregar al selector de QR

En el <select id="qr-select-places"> agrega:

<option value="salon10">Salón 10</option>
